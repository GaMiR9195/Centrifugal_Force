# Centrifugal Force

Ходьба по стенам и наклонным плоскостям Sable sub-level'ов. NeoForge 1.21.1, Sable 2.0.3+.

## Как это устроено

- **Ориентация.** `EntitySubLevelUtil.getCustomEntityOrientation` отдаёт `R = Q * S`, где `Q` —
  ориентация sub-level'а, `S` — ориентация бокса в его локальном пространстве. Внутри физического
  тика значение зафиксировано, между тиками интерполируется для камеры и рендера.
- **Хитбокс.** Sable вращает бокс вокруг ванильного глаза, поэтому всё считается через центр бокса
  (`centre = position + eye - R * (eye - height/2)`), а позиция получается обратной подстановкой.
- **Контакты.** `extent(n)` — полуширина бокса вдоль `n`; касание плоскости это
  `centre*n = plane + extent(n)`. Поворот на угол держит два контакта сразу, поэтому бокс катится
  по ребру, а не проваливается в пол или в стену.
- **Перенос кадром.** `CollisionInfo.inheritedMotion` перезаписывается чистым переносом точки опоры
  между `lastPose()` и `logicalPose()`.
- **Гравитация** перенаправляется вдоль локальной вертикали в пост-тике.

## Структура

| Файл | Ответственность |
| --- | --- |
| `internal/AdhesionEngine` | все решения тика: захват, опора, переход, позиция, гравитация |
| `internal/AdhesionState` | состояние игрока и заморозка ориентации на физический тик |
| `internal/Hitbox` | геометрия ориентированного бокса, контакты, углы |
| `internal/SurfaceProbe` | лучи по блокам sub-level'а в локальном пространстве |
| `internal/Transition` | таймлайн поворота и удерживаемые плоскости |
| `internal/Rotations` | оси, сглаживание, кватернионы |
| `mixin/EntitySubLevelUtilMixin` | отдаёт ориентацию Sable |
| `mixin/EntityFrameCarryMixin` | переписывает перенос кадром |
| `mixin/EntityAdhesionStateMixin` | поле состояния на `Entity` |
| `mixin/DebugScreenOverlayMixin` | строки состояния на экране F3 |

Адгезия считается для локального игрока: Sable доверяет позицию клиента и не считает OBB для
`ServerPlayer`.
